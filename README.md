# Zaki Abbas — Next.js Site

Production-ready Next.js 15 (App Router) port of the Zaki Abbas website.

## Stack

- Next.js 15 (App Router)
- React 19
- CSS (ported design system)
- next/font (Sora + Manrope)
- next/image

## Develop

```bash
cd za-next
npm run dev -- --hostname 0.0.0.0 --port 3000
```

## Build

```bash
npm run build
npm start -- --hostname 0.0.0.0 --port 3000
```

## Routes

- `/` Home
- `/about`
- `/services`
- `/machinery`
- `/contact`
- `/sitemap.xml`
- `/robots.txt`

## Business config

Edit `src/lib/site.js` for contacts, brands, services, machines.

## Assets

Public images in `public/assets/images/`
